Dispersibility Analysis Toolkit

Quantifying aerosol dispersibility using the Wasserstein distance

Standard aerosol characterization collapses rich particle size distribution data into summary statistics that obscure clinically relevant variability. This toolkit implements a distribution-sensitive analytical framework based on the Wasserstein distance (Earth Mover's Distance) to quantify how closely an inhaler-generated aerosol approaches a powder's intrinsic dispersion limit. The metric is formulation-agnostic, physically interpretable, and works with standard laser diffraction data.

Language: R

Publication: Xia G, Dechayont B, Che L, Comfort I, Brunaugh AD. A distribution-based metric for quantifying dispersibility in dry powder inhalers. Pharmaceutics, 2026.

Data: Raw laser diffraction datasets (Deep Blue Data)

In Development

bioHLB Toolkit

A sequence-informed framework for studying and predicting how proteins partition at biological interfaces. The project is being developed to connect molecular identity with adsorption behavior, competitive surface assembly, and downstream biological fate.

In active development; methods and code will be released when they are ready for external use.

DiffractoMorph

A measurement and modeling framework for observing particulate systems as they dissolve, reform, or reorganize. DiffractoMorph combines time-resolved angular-scattering measurements with dissolved-phase mass balance, calibrated observation operators, and minimum-sufficient models so that measured changes can be separated from model-dependent interpretations.

In active development; methods and code will be released after validation.
